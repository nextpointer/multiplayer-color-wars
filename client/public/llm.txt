# Color Wars

> Color Wars is a real-time multiplayer chain-reaction strategy browser game for 2–8 players.

## Canonical URL
- Primary: https://color-wars.nextpointer.dev/
- Alternate deployment: https://multiplayer-color-wars.vercel.app/

## Summary
Players claim a starting cell on their first turn (placed as 3 dots), then add dots only to cells they already own. When a cell reaches critical mass (2 in corners, 3 on edges, 4 in middle), it explodes, sends one dot to each orthogonal neighbor, captures them, and can trigger chain reactions. Last player with cells remaining wins.

## Key facts
- Genre: strategy, multiplayer, chain reaction, board/browser game
- Players: 2-8
- Platform: web browser (desktop and mobile)
- Realtime: WebSocket-based rooms with reconnect/rejoin support
- Cost: free to play
